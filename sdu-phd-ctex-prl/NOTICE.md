# 权利、素材与分发说明

本项目为根据用户提供封面制作的非官方学位论文模板。学校名称、校名校徽以及用户封面中的信息仍归相应权利人 / 信息主体，本项目不授予校名校徽的额外使用权，也不表示学校背书。

`assets/cover-reference.pdf` 和 `assets/sdu-logo.png` 来自用户提供的封面。源代码压缩包和示例 PDF 含该封面的个人信息，请勿作为匿名送审材料或未经处理的公开通用模板分发。

所有 .cls、.tex、配置与检查脚本均可由用户为论文写作自由修改。第三方 TeX 包由用户的 TeX 发行版提供，遵循各自许可证。本项目不包含任何字体文件；使用者应自行确认字体来源、授权及 PDF 嵌入条件。
